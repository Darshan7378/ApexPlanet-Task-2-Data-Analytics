# ApexPlanet Task 2 – Data Analytics

## Project Overview
This project was completed as part of my ApexPlanet Data Analytics Internship.

The objective was to analyze a sales dataset and identify meaningful business insights.

## Work Completed

- Exploratory Data Analysis (EDA)

- Correlation analysis
- Data visualization
- Business insights and final report

## Tools Used
- Python
- Pandas
- SQL
- Excel
- Data Visualization

## Key Finding
The dataset contains 1,000 sales records, with total sales of approximately ₹13.94 crore.
